# Академия Одаренности

Интерактивный одностраничный образовательный сайт к лекции «Психолого-педагогическая диагностика способностей и одаренности».

## Структура

- `index.html` — все разделы лекции, интерактивы и список литературы
- `css/style.css` — светлое средневековое фэнтези, адаптивная верстка, анимации
- `js/main.js` — навигация, прогресс пути, игры и сохранение прогресса в localStorage
- `js/three-scenes.js` — легкие процедурные 3D-сцены на Three.js
- `assets/` — папка для дополнительных изображений и шрифтов

## Публикация на GitHub Pages

1. Откройте репозиторий: https://github.com/toshaandtob/giftedness-academy
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Нажмите **Save**.
5. Через 1–3 минуты сайт будет доступен по адресу:

https://toshaandtob.github.io/giftedness-academy/

## Особенности

- Одна длинная прокручиваемая страница без аккордеонов, вкладок и модальных окон
- Игры на сортировку, соответствие, поиск, исследование и сборку принципов
- Прогресс игр сохраняется в браузере через localStorage
- 3D-сцены создаются процедурно, без тяжелых внешних моделей
- При отсутствии WebGL показывается понятная альтернатива, а игры остаются доступными
- Адаптивность проверена для экрана от 360 px
